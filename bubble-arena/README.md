# 💧 버블 아레나 (Bubble Arena)

크레이지 아케이드에서 영감을 받은 미니 로컬 2인 대전 웹 게임입니다. 빌드 과정 없이 순수 HTML/CSS/JS(Canvas)로 동작합니다.

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 로컬 서버로 열고 싶다면:

```bash
cd bubble-arena
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 게임 방법

한 화면, 한 키보드로 두 명이 대전합니다. 물풍선을 설치해 상대를 가두고 터뜨리면 승리합니다. 벽(연한 파란 블록)은 물풍선으로 파괴할 수 있고, 회색 벽은 파괴되지 않습니다.

| | Player 1 | Player 2 |
|---|---|---|
| 이동 | `W` `A` `S` `D` | `↑` `↓` `←` `→` |
| 물풍선 설치 | `Space` | `Enter` |
| 시작 / 재시작 | `R` | `R` |

라운드가 끝나면 점수가 누적되고, `R` 키로 바로 다음 라운드를 시작할 수 있습니다.

## 참고

- 원작 크레이지 아케이드 특유의 "물풍선에 갇혔다가 동료가 터뜨려 구해주는" 협동 메카닉 대신, 단순화된 폭탄 설치형(봄버맨 스타일) 규칙으로 구현했습니다.
- 사운드는 외부 파일 없이 Web Audio API로 즉석에서 생성합니다.
